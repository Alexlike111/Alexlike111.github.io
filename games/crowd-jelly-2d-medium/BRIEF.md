# Crowd Jelly 2D (версия medium, эксперимент medium/high/xhigh)
Ядро: 2D-бегалка толпы желе, 3 дорожки, ряды ворот (+N, ×2, −N, ÷2), пилы, отряды врагов, босс в конце.
Цель Саши (22.10): число человечков сохраняется между раундами; карта открывается только при нужном числе (REQ в src/levels.ts: 0, 30, 90, 300, 1k … 900k); числа на картах подстраиваются под число (масштаб = толпа игрока в пределах 1x..4x уровня карты); максимум 1 000 000.
Толпа = ОДНО число (счётчик); на экране рисуется до 64 желе (visibleCount).
Баланс: каждая карта строится контроллером: идеальный путь растёт ×2.4 до босса (стена босса = 45% толпы на пути), после босса итог ≈ ×1.8 для идеальной игры. Бот (npm run sim в qa) показывает победу 50–75% при 35% ошибок.
Поражение: остаётся 90% толпы (минимум 10). Победа на карте 12 = ровно 1 000 000 (MAX).
Покупки не включены (CJ-08). Реклама: только по тапу после итога (kit/ads). Бонус «+25% желе» — rewarded.
Метрики: run_end {level, win, crowd_start, crowd_end, mistakes, maps_open}, map_unlocked.
Проверки: npm run check (общий, токен Playgama плейсхолдер: --allow-placeholder), node qa/game.mjs (правила игры).
