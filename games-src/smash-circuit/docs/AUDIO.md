# Audio

## STATUS: PLACEHOLDERS - MUST BE REPLACED BEFORE PUBLISHING

Every file in `public/sfx/` is **synthesized by code** (`scripts/make-sfx.sh`, ffmpeg expressions).
Playgama requirement **3.3.2 forbids sound that is synthesized in code**, so the game **cannot be published**
with these files. Replace each one with a recorded sound under a CC0 / properly licensed source
(keep the licence + author in the table below), keeping the **same file name, same role (loop / one-shot)**.
Requirement **3.3.1** also needs real background music: replace `music.*` with a recorded track.

`bash scripts/make-sfx.sh` regenerates the placeholders (needs ffmpeg with libvorbis + libmp3lame).
**Do not run it after the recorded files are in place** (it overwrites them).

## Format
- `name.ogg` (Vorbis, primary) and `name.mp3` (fallback: Safari / iOS where decodeAudioData cannot read Ogg).
  `AudioManager` picks `ogg` when `canPlayType('audio/ogg; codecs="vorbis"')` is truthy, else `mp3`.
  If you only deliver one format, deliver mp3 + ogg anyway, or change `pickExt()` in `src/audio/audio.ts`.
- Mono, 44.1 kHz, peak around -3 dBFS, no leading silence (the engine/skid/music loops must loop seamlessly).
- Total budget: keep the folder under ~1.5 MB.

## Collision sounds (scripts/make-impacts.mjs)
`node scripts/make-impacts.mjs` renders every `impact_*`, `crunch_*`, `debris_*`, `scrape` file (ogg + mp3) into `public/sfx/` and a
demo mix into `e2e/out/audio/impact_demo.{wav,mp3}`. Layers: pitch-dropping low thump + material resonances (inharmonic metal modes, wood
knock, concrete slap, plastic bonk) + crumpling-metal grains + short debris rattle; 28 Hz DC/rumble high-pass, 4-6.5 kHz gentle low-pass
(no harshness), tanh soft limiter (no clipping), RMS-normalised per family, peak <= -3 dBFS, short tails. ~150 KB for all variants.
(The old single `impact_light/impact_heavy/crunch/debris` files clipped at 0 dBFS with flat tops and a hard noise burst; they are gone.)
Same synthesis caveat as above: swap for recordings if the platform review requires it, keeping names `<family>_<n>`.

## Behaviour (src/audio/audio.ts)
- Collision pipeline (`onImpact`): material by `other` (wall/curb/road -> concrete, guardrail/car -> metal, prop -> plastic or wood; `break` events use
  `propType`), random variation (never the same twice in a row), +-4% random pitch plus lower pitch for stronger hits, volume ~ strength, heavy hits
  layer `impact_heavy` (+ `crunch` > 0.55, `debris` > 0.7).
- Loudness normalisation: each collision buffer is trimmed at load to its family's target RMS (`FAMILY_RMS`).
- Pile-ups: global min interval (`CONFIG.audio.impactMinInterval`), per-material interval, leaky energy bucket, max 6 impact voices (louder hit steals
  the quietest), impact bus -> DynamicsCompressor.
- Ducking: every impact briefly dips the engine/skid/scrape bus (<= 45 %) and music (<= 35 %), then releases in ~0.3 s.
- AI-car impacts: volume x 0.6 x proximity^1.5 and a per-voice low-pass that closes with distance.
- Wall sliding: weak wall/guardrail/curb impacts are suppressed while `scrape` events arrive; a quiet looping `scrape` sample fades in/out instead.
- The `AudioContext` is created lazily and unlocked by the first `pointerdown` / `keydown` / `touchend` / `click`.
- `setMuted(m)`: master gain (user setting and `platform.isAudioEnabled()`; the caller ORs them).
- `setPaused(p)`: hard pause = `AudioContext.suspend()` (platform pause event, ad open, tab hidden). Total silence.
  The manager also suspends itself on `document.hidden`.
- `setGameplayPaused(p)`: soft pause for the in-game pause menu: engine/skid silent, music ducked, UI sounds still play.
- `update(player, dt)` every frame (pass `null` in menus), `onEvents(events, playerId)` with the drained SimEvents.
  Impact/break/scrape volume falls off with distance from the player (`CONFIG.render.fx.shakeNearRadius * 1.4`).
- All volumes / rate ranges / rate limits: `CONFIG.audio`.
- Every method is a no-op when Web Audio or a file is missing.
