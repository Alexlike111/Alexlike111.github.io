# Правила для агента (Unreal через MCP)

Цикл на каждый этап: **план → изменение через MCP → компиляция → запуск PIE → лог и скриншот → исправление**. Не переходи к следующему этапу, пока текущий не проверен.

- Работай только внутри папки проекта. Не трогай систему и другие каталоги.
- Blueprint-графы через MCP/Python собираются плохо. Для игровой логики пиши **C++ или Python-скрипты**, Blueprint оставляй для тонкой настройки. Если без ручного Blueprint не обойтись — остановись и опиши пользователю точные шаги.
- Вызовы MCP идут последовательно на game thread — не отправляй их параллельно.
- Перед массовыми изменениями делай `git commit` проекта (включи Git/Perforce-ignore для Intermediate, Saved, Binaries, DerivedDataCache).
- Не выдумывай результат: если не удалось запустить или проверить, так и скажи.
- Экономь токены: короткие логи, скриншоты только на контрольных точках, не читай огромные файлы целиком.
- После каждого этапа — краткий отчёт: что сделано, что проверено, что осталось ручным.
