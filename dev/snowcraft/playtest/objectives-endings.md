# SNOWCRAFT: цели, прогрессия и концовки (плейтест)

Сборка: `shots/swarm/build` (в ней нет цели «откопать дверь», которая есть в `src/game/quest.ts`). Скрипты и вывод: `shots/swarm/objectives-endings/run1–run5`. Скриншотов нет: проверка текстовая (строки целей, состояние игры), шесть прогонов использованы.

## 1. Вердикт
Рассвет работает: сон с 21:00 на 11-й день дал концовку «dawn» на 12-м дне около 11:00. Ледокол проверен частично: сигнальный костёр зажигается, но записку смотрителя (знание мачты) в headless не удалось подобрать, поэтому рация не чинилась. Цепочка целей короткая и обманчивая: иглу засчитывается само, рация «готова» раньше починки, а дальше игрока ждут 20 реальных минут счётчика и около 80 минут без целей.

## 2. Находки
- **F1, блокер (проверить вручную):** записка s2 (знание мачты, станция у стола) не подбиралась клавишей E: 0 из 6 попыток с точной позиции (run5, `A pick s2`). Записка n7 подобралась с первой попытки (run4). Без мачты нет рации и Ледокола. Вероятно, E берёт «ближайшее» другое (tools.ts `interactAction`, `holdE`).
- **F2, важно:** цель «Утепли жильё до ★★» засчитывается при входе в дом станции: ★★★, закрыто, без печки (run3: `shelterGoal: true` на первой минуте). Урок снежных блоков и иглу пропадает.
- **F3, важно:** цель «Почини рацию 3/3» засчитывается при подборе деталей в сумку (`radioParts()` считает инвентарь). Текста «вставь в рацию» нет, игрок видит «Узнай про мачту» (run2).
- **F4, важно:** после починки рации `objectiveText()` возвращает только «Жди ледокол: N дн.». Два игровых дня (около 20 реальных минут) без целей и без подготовки к сигналу.
- **F5, важно:** ракетница и ракеты (станция: 1 + 3; корабль: 2) не связаны с концовкой. `tools.ts:696` только звук.
- **F6, важно (скука):** после «fur» единственная строка «Дотяни до рассвета: день N из 12». После концовки строка пустая (`questState.ended`). Разрыв 8 игровых дней.
- **F7, мелочь:** цель «supplies» никогда не выводится как цель (цикл ломается на ней). Рассвет около 11:00, а в §2 дизайна 12:00.

## 3. Исправления
- **F1:** записки подбирать автоматически в радиусе 6 клеток (`nearby.ts`, `pickDrop`). Сначала воспроизвести на ручном тесте. M, эффект 5.
- **F2:** `quest.ts`, `on('shelter')`: засчитывать, только если построено ≥3 блоков (`runStats.blocks`) и игрок не в зоне станции (`LOC.station`). S, эффект 4.
- **F3:** `radioParts()`: считать вставленные (`radio.data.have`), текст «Вставь детали в рацию: N/3». S, эффект 4.
- **F4:** при `icebreakerAt > 0` выводить «Ледокол: N дн. · сигнал: 2 полена, ягель, спички» и вторую строку с открытой целью (тюлень или мех). S, эффект 3.
- **F5:** `tools.ts:693`: выстрел ракетой в 160 клеток от `LOC.summit` при прибытии ледокола зажигает сигнал. Иначе убрать ракеты из `locations.ts:534/800`. S, эффект 3.
- **F6:** 4–6 целей после «fur»: «Переживи пургу ★★», «Сшей парку», «Добудь тюленя ×3». За 2 дня до рассвета строка «До рассвета: N ч». M, эффект 4.
- **Граф (оценка по ходьбе 27 клеток/с и 2.4 игр. мин/с, не замер):**
  печь (1 мин) → барометр (1) → журнал s1, гарпун (0) → иглу ★★ (8–12, сейчас пропускается) → плавник ×6 (2) → дневник n1, лампа (2) → тюлень, жир (5–10) → «Заря» (3) → 3 детали: корабль, шахта, снег над аккумулятором (10) → мачта (знание s2 + 3 доски + 2 верёвки) → рация → 2 дня ожидания: сигнальный костёр → «Ледокол». Мех (n7) и пурги идут параллельно. Каждая цель: тост и строка в журнале.

## 4. Три быстрые победы
1. F2: шкала укрытия не засчитывает станцию (S, эффект 4).
2. F3: рация засчитывается после вставки, а не подбора (S, эффект 4).
3. F5: ракеты либо зажигают сигнал, либо убираются из мира (S, эффект 3).
