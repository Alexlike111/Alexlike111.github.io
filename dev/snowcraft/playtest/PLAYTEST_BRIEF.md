## The game
2D pixel Arctic survival sandbox (endless; polar night with 12-day night / 6-day twilight rings). You start at a research station on a cape at −25 °C. Goal line (top-centre) teaches the first steps: pick up coal → dig out the door → light the stove → read the barometer → read the keeper's log → build an igloo from snow blocks. Then free survival: warmth (stove, fuel), food (cans, hunting, fishing), water (melt snow), sleep, storms, a polar bear, a husky «Север», sea ice drift, 17 usable items (compass, thermos, bandage...), radio, icebreaker crates. Controls (desktop, Terraria-like): WASD move, Space jump, Shift run, LMB (hold) use the item at the cursor (dig/cut/place/strike), RMB interact (doors, chests, stove, beds...), wheel or 1–6 select belt cell, Esc/I/C inventory, P pause+settings, J journal, F eat, V parka, G drop, Ctrl-tap smart cursor, Ctrl+wheel zoom, «?» key list. Loose items near you are picked up automatically. Phone: fixed stick bottom-left, icon buttons right (Действие, Прыжок, Взять, Пояс, Чутьё, Парка), top row Сумка/Журнал/⚙.

- ACT with REAL input only: page.keyboard.down/up/press, page.mouse.move/down/up/click (button:'right' for RMB), page.mouse.wheel, page.touchscreen.tap / CDP touch for phone. `window.__sc.step(n)` / `stepFast(n)` advance n game frames (60 per second) — use it to let time pass between real inputs, NOT to perform actions (no __sc.give/teleport to progress, except where your persona text allows teleport to skip a long dull walk: say so in the report). Use __sc.G (game state) and __sc.stats() only to READ values (temperature, hp, time of day, position).
