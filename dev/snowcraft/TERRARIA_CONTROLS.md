# SNOWCRAFT v13: controls, layout and world interaction «как в Terraria» (owner request)
Owner decisions: take the SCHEME and LAYOUT of Terraria (mouse-first), keep our own art, names and world. Belt stays **6 cells** (9 with the belt pouch). Phone (touch-ui) keeps its current layout (stick bottom-left, icon buttons) — only the desktop layout changes; touch gets the interaction rules that apply (auto-pickup).

## Desktop controls (Terraria mapping)
- **LMB** (hold) = use the selected item at the cursor: dig / cut / place / strike / throw / eat (unchanged logic in tools.ts). **RMB** = interact with what is under the cursor (or nearest in reach if the cursor is on empty space): doors, containers/chests (opens the search panel), stove/lamp/kettle/radio/station objects, beds (sleep), snares, pick up a loose item. Fallback only when nothing is interactive: with the shovel, RMB-hold tamps snow (as today). **E** stays as a silent alias of RMB's interact (old muscle memory, tests); F eat, V parka vent, X senses, G drop, R dome/cursor, Q hold = belt wheel: all unchanged but no longer advertised except in the full key list («?»).
- **Mouse wheel** = previous/next belt cell (already). **1–6** (1–9 with the pouch) = select cell (already). **Esc or I or C** = open/close the inventory (Terraria: Esc toggles the inventory; if the inventory/journal/near-list/settings are open, Esc closes them first). **P** = pause + the settings panel (menu.ts, also the ⚙ button). **J** = journal (unchanged). **Shift+LMB** on an item in the inventory = quick move (belt ↔ bag, already); **Left Ctrl** (tap, without wheel) = toggle the smart cursor (Terraria); Ctrl+wheel and +/- stay zoom. Dropping: G or drag out of the panel (already).
- **Auto-pickup** (Terraria): loose items within ~10 cells of the player fly into the pack (needs weight room: if it would exceed WEIGHT_MAX leave it and show one «Слишком тяжело» toast per item per 5 s); items the player dropped/threw, and items still falling in the first 0.6 s, wait 1.4 s before they can be auto-picked; containers and heavy fixtures are NOT auto-picked (RMB). A small floating «+1 Уголь» text rises from the pickup spot (Terraria-style, reuse the toast style or a tiny canvas/DOM floater; stack counts in one text).
## Desktop layout (Terraria mapping, hud 'full' and 'min' modes both)
- **Top-left: the belt** (6/9 cells, selected cell highlighted, key numbers, selected item name under it for 1.5 s) — Terraria's hotbar. Inventory panel opens **anchored top-left right under the belt** (not centred): bag grid, the wear slots in a column to the right of the grid, the crafting list («Что умею») below/next to the grid as Terraria's crafting column; container/search panel to the right of it.
- **Top-right: vitals** = body figure + core temperature + the day/clock chip (stacked), the ⚙/⛶ buttons stay in the very top-right corner row above or beside them; the compass plate below the chip. Goal line stays top-centre, small.
- **Bottom: empty** (maximum view): no belt there, no key hint box by default (the «?»/H full key list stays reachable from the settings panel and the key H), toasts stack bottom-left small (Terraria chat-like, max 3, fade in 4 s). Item/world hover tooltip follows the cursor (existing).
