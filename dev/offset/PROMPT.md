# СДВИГ / OFFSET — мастер-промт (для ведущего агента и субагентов)

> Этот файл — единственный источник правды. Любой агент читает его целиком перед работой.
> Если код и промт расходятся — правь промт вместе с кодом, не молча.

## 0. Роль
Ты — студия из одного человека уровня AAA: геймдизайнер, физик-программист, арт-директор, саунд-дизайнер и QA.
Ты делаешь не «демо с телепортом», а игру, в которую хочется вернуться завтра. Ты не сдаёшь то, что сам не запускал и не видел.

## 1. Что мы делаем
**«СДВИГ» (EN: OFFSET)** — 2D сайд-вью роглайт про человека, который умеет прыгать сквозь пространство.
Оригинальная вселенная «по мотивам жанра» (телепортёр-беглец и охотники). **Запрещено** использовать имена, персонажей,
организации, сюжет и узнаваемые образы любых существующих книг/фильмов/игр. Никакой крови и расчленёнки.

Мир — это печатный лист. Реальность «напечатана» тремя красками. Герой — **Брак** (Misprint): оттиск, выпавший из приводки,
поэтому может сдвигаться между слоями. Охотники — **Регистр** (The Register): хотят вернуть всё «в приводку».
Забег = «тираж», комната = «лист», валюта = «краска», постоянные улучшения = «формы».

## 2. Столпы (по ним принимаются все решения)
1. **Телепорт как физика, а не как рывок.** Сохранение импульса. Вытеснение воздуха: хлопок-имплозия в точке ухода,
   ударная волна в точке прибытия. «Шрам» в пространстве на несколько секунд. Тяжёлый прыжок = обмен объёмами:
   всё, что в сфере вокруг героя (обломки, враги, куски стен), уезжает вместе с ним.
2. **Разрушаемость — это оружие.** Стены из выпуклых ячеек Вороного, граф связности, отвалившиеся острова падают
   как твёрдые тела и крошатся дальше. Урон врагам — в основном физический: удар о стену, обломок, падение.
3. **Боёвка в три глагола:** прыгнул → ударил/схватил → унёс/швырнул. Глубина — из комбинаций и импульса, не из кнопок.
4. **Управление одной мыслью.** Телефон — первый класс. Левый палец — движение. Правый: тап = прыжок в точку / удар по врагу,
   тяни = точное прицеливание в слоумо, держи дольше = тяжёлый прыжок. Одна контекстная кнопка «ХВАТ».
5. **Удержание.** Каждый забег отличается (комнаты, мутации прыжка), каждый забег что-то оставляет (краска → формы,
   открытия, оттиски-достижения, уровни тиража, ежедневный лист).
6. **Свой стиль: ризограф-брак.** Три краски + бумага, растр, зерно, сбой приводки. Телепорт = слои на миг разъезжаются.
   Никаких неоновых градиентов, glassmorphism, скруглённых «карточек», эмодзи и прочего «ИИ-дефолта».

## 3. Стек и почему
| Задача | Инструмент | Почему |
|---|---|---|
| Физика твёрдых тел | **Rapier2D** (`@dimforge/rapier2d-compat`, WASM) | самый быстрый 2D-солвер для веба, CCD, события силы контакта, составные тела; wasm вшит base64 → один html |
| Разрушение | свой модуль: Вороной через отсечение полуплоскостями + граф связности | все ячейки выпуклые → коллайдеры `convexHull` без декомпозиции; полный контроль над бюджетом |
| Рендер | свой **WebGL2**-батчер «в печатные формы» + пост-композит | сцена рисуется как плотность трёх красок (RGB = формы), пост-шейдер печатает их на бумагу: растр, зерно, сдвиг приводки, искажения |
| UI | DOM/CSS поверх канваса | чёткий текст, вёрстка, локализация RU/EN |
| Звук | WebAudio, полностью процедурный синтез | 0 байт ассетов, адаптивная музыка |
| Сборка | Vite + TypeScript + `vite-plugin-singlefile` | как остальные игры репозитория; результат — один `index.html` |
| QA | Playwright (предустановлен) + встроенный отладочный API `window.__offset` | скриншоты, бот-прохождение, замер шага физики |

Координаты: метры, **y вниз**, гравитация ≈ 26 м/с². Герой ≈ 1.7 м. Фикс-шаг физики 1/60, рендер с интерполяцией.

## 4. Архитектура (`dev/offset/src`)
```
main.ts            загрузка, цикл, склейка
core/   bus.ts (типизированные события)  math.ts  rng.ts (сидируемый)  save.ts  i18n.ts  tune.ts (ВСЕ числа баланса)
gfx/    gl.ts (батчер, формы)  post.ts (композит)  draw.ts (примитивы)  fx.ts (частицы, шрамы, волны)  camera.ts
phys/   world.ts (Rapier-обёртка)  fracture.ts (Вороной)  structure.ts (ячейки, граф, острова, материалы)
game/   player.ts  teleport.ts  input.ts  enemies/*.ts  projectiles.ts  props.ts  level/*.ts  run.ts  upgrades.ts  meta.ts
ui/     hud.ts  screens.ts  ui.css
audio/  audio.ts (sfx)  music.ts
```
Правила:
- Модули общаются через `bus` и узкие интерфейсы; **никаких чисел баланса вне `tune.ts`**.
- Рендер не знает про геймплей: получает списки примитивов «форма/плотность».
- Всё, что создаёт тела, обязано их удалять; бюджеты: ≤ 260 динамических тел, ≤ 1500 частиц; при превышении — самые старые обломки растворяются.
- Никаких внешних сетевых запросов в рантайме. Никаких растровых ассетов.

## 5. Библия стиля
- **Бумага** `#EDE3CF` (тёплая кость, с волокном). **Формы** задаются набором красок биома; базовый: индиго `#2B2F86`, коралл-флуо `#FF4F3F`, солнце `#F5B915`.
  Наложение красок — умножением: индиго+коралл = почти чёрный бордо, коралл+солнце = оранж, индиго+солнце = хвоя.
- Плотность < 1 печатается растром (у каждой формы свой угол). Сплошные заливки слегка «недокатаны» (зерно, полосы валика).
- Постоянный микросдвиг форм ≈ 0.6 px; на прыжке — рывок до 10–14 px вдоль вектора прыжка и пружинный возврат.
- Герой = индиго-силуэт + коралловый шарф (верле-ткань). Регистр = индиго + «солнце» (ровные, геометричные, с крестами приводки).
- UI = пробный оттиск: кресты приводки ⊕, обрезные метки, контрольная шкала цвета (это полоса здоровья), сигнатуры «ЛИСТ 03/09»,
  тексты как типографские пометки. Шрифты: **Unbounded** (заголовки/цифры), **Martian Mono** (служебные). Углы прямые. Тени — только как сдвинутый оттиск.
- Движение UI: штамп (резкий въезд + микросдвиг слоёв), а не плавные fade/scale.
- Тон текста: сухой типографский жаргон. Коротко. Без восклицаний и эмодзи.

## 6. Планка качества и рубрика критиков
Каждая зона оценивается независимым критиком по 10-балльной шкале. **Цель: ≥ 9 в каждой.** Критик обязан запускать игру, а не читать код.
1. Ощущение телепорта (отклик < 60 мс, импульс читается, эффект «дорогой»)
2. Физика и разрушаемость (правдоподобие, каскады, стабильность, нет «взрыва» солвера)
3. Боёвка (читаемость, варианты решения, удовольствие от удара)
4. Управление на телефоне (одной мыслью, без промахов, обе ориентации)
5. Визуальный стиль (оригинальность, цельность, читаемость на 6" экране)
6. UI/UX и онбординг (понятно без текста за 30 секунд)
7. Звук и музыка
8. Прогрессия и удержание (причина для «ещё один забег», причина вернуться завтра)
9. Контент и разнообразие (враги, комнаты, мутации, синергии)
10. Производительность и стабильность (60 fps на среднем телефоне, 0 ошибок в консоли, нет софт-локов)
Оценка ниже 9 = список конкретных дефектов с воспроизведением → исправить → переоценить.

## 7. Протокол самопроверки (обязателен для всех)
1. `npm run check` (tsc) — чисто.
2. `npm run build` — чисто; один `dist/index.html`.
3. `node scripts/shot.mjs <сценарий>` — посмотреть скриншоты **глазами** (десктоп 1280×720, телефон 844×390 и 390×844).
4. `node scripts/bot.mjs` — бот играет N забегов: 0 ошибок консоли, шаг физики p95 < 6 мс, нет NaN, нет зависших комнат.
5. Не объявлять «готово», пока сам не увидел результат. Проблему — чинить, а не описывать.

## 9. Порядок работ
1. Каркас, рендер «в формы», физика, разрушение — **играбельный прототип прыжка** → скриншоты → самооценка.
2. Герой, боёвка, враги, снаряды → бот-тест.
3. Генерация листов, цикл забега, мутации, мета-прогрессия, сохранения.
4. Параллельно субагенты: звук/музыка; UI-экраны и локализация.
5. Волна критиков по рубрике → исправления → повтор, пока не ≥ 9.
6. Сборка в `play-test/offset/`, запись в `play-test/index.html`, коммит и пуш.
