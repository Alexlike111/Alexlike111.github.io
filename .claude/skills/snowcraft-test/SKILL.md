# Проверка SNOWCRAFT одной командой

Проект: `dev/snowcraft` (TypeScript + Vite, один HTML). Дизайн: `DESIGN.md`, контракт: `SPEC.md`, состояние: `notes-wave2.md`.
Правила: FPS в облачном браузере не измеряем (нет видеокарты), это делает владелец на телефоне через «Самотест». Звук на слух не проверить: только самотест `[audio]`. Не публиковать на Playgama и не тратить без явного «да» владельца.

## 1. Автопроверки (всегда по порядку, остановка не нужна, собери все результаты)
```bash
cd dev/snowcraft
npx tsc --noEmit
npx tsx tests/sim.test.ts        # движок (ожидается 40/40)
npx tsx tests/world.test.ts      # мир
npx tsx tests/mine.test.ts       # шахта
node tests/e2e.mjs               # игра на ПК и телефоне, консоль без ошибок, самотест
npx vite build                   # dist/index.html
```
Самотест в игре: `dist/index.html#selftest`, отчёт в `shots/selftest.txt`. Падение любой проверки кроме строк про FPS это дефект.

## 2. Скриншоты (смотри глазами через Read)
`node tests/world-shots.mjs` (зоны, день 1, ночь, буря), `node tests/ui-shots.mjs` (HUD, сумка, журнал, Чутьё), ПК 1600×900 и телефон 844×390 с касанием. Проверь: наложения HUD, шрифты (Jura в HUD, пиксельный только в заголовках), контраст ночью, кнопки ≥ 48 px, центр экрана свободен.

## 3. Игровой прогон
Открой `dist/index.html?title=0` в Playwright, играй реальными событиями клавиатуры и касаний: цель на экране, срезать плотный наст, построить иглу, зажечь лампу, прочитать записку, Чутьё (X), сумка (C), журнал (J), обыск сундука, масштаб. Скриншоты каждые несколько секунд. Для баланса: бот через `window.__sc` проходит 12 дней на каждой сложности и пишет по дням топливо, еду, воду, минимум ядра, обморожения, пережитые пурги.

## 4. Оценки (1-10, с одной фразой почему)
**Разработчик:** архитектура и контракты, чистота кода, покрытие тестами, устойчивость (сохранения, сброс состояния, softlock), производительность по коду (аллокации в горячих циклах, без измерений), долг и риски.
**Игрок:** первое впечатление и графика, оригинальность (не копия известных песочниц), управление ПК, управление телефон, физика «вау», напряжение выживания, снегоделие, ясность целей в первые 30 секунд и первая победа за 5 минут, баги.

## 5. Отчёт
Сделай страницу-артефакт (Artifact): две колонки Разработчик/Игрок, оценки, скриншоты, список правок по важности (критично, важно, мелочь), что требует проверки владельцем на телефоне (FPS, звук, iOS). В конце одной строкой напомни владельцу про расход токенов и лимитов.
